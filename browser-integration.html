Firefox beta

Send Firefox downloads to DOWNitUP

The official Firefox add-on connects to the DOWNitUP desktop app running on your computer. Send links, images, audio, video, selected URLs, or the current page through the browser context menu.

Install for FirefoxGet the desktop app

1. Install desktop

Install the beta desktop app for Windows, macOS, or Linux and keep it running while using the extension.

2. Add Firefox extension

Install version 0.1.0 from Mozilla Add-ons. Pairing with the local desktop service happens automatically.

3. Send a download

Right-click a supported link or use optional download capture. If the desktop app is unavailable, the extension can pass the transfer back to Firefox.

Permissions and privacy

The extension needs broad website access and download-history permissions so it can read the selected download URL and relevant request details, then forward them to the desktop service at 127.0.0.1. It does not send those download details to a DOWNitUP cloud service.

Browser URLs, headers, and page context can be sensitive. Enable automatic capture only if you understand the permissions shown by Firefox, and review the Mozilla disclosure before installing.

Troubleshooting

  • Confirm the DOWNitUP desktop app is open and up to date.
  • Temporarily disable other download-capture extensions to rule out conflicts.
  • If capture fails, use the context-menu action or paste the URL directly into DOWNitUP.
