Download Manager for Android

Download direct files, magnet links, and torrent files from one app. Pause and resume supported transfers, run downloads in the background, and use up to 16 parallel connections when the source server allows it.

Get it on Google Play

Direct files and torrents

Handle HTTP and HTTPS links alongside magnet links and .torrent files without switching apps.

Resume with control

Pause downloads and continue them later when the source supports range requests. Track active, queued, and completed items clearly.

Works with other apps

Share download URLs and magnet links to DOWNitUP from browsers and other Android apps.

Requirements and pricing

DOWNitUP supports Android 7.0 and later. The core app is free. Optional rewarded ads and optional in-app support purchases help fund development; watching an ad is not required for normal downloading.

Download features depend on the source server. Parallel connections and resume are used only when the server supports them.
